# ATM System Using Python

## Project Description
This is a simple ATM System developed using Python.
It uses an Excel file to store account details and balances.

## Features
- Create a new account
- Deposit money
- Withdraw money
- View account balance
- Store data in an Excel file

## Technologies Used
- Python
- OpenPyXL
- Microsoft Excel

## How to Run
1. Install Python.
2. Install the required library:
   pip install openpyxl
3. Run the Python program.
